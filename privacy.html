1. このポリシーの対象

このポリシーは、AIKA Channel Tools（以下「このツール」）が YouTube API サービスを通じて受け取る情報を、どう扱うかを定めたものです。「このツール」は、同じ Google の認証の設定（OAuth クライアント）を使う、運営者のプログラムすべてを指します。

このツールは、YouTube チャンネル「AIKAの10分でわかるAIニュース【毎朝7時更新】」の運営者（以下「運営者」）が自分で作り、自分のパソコンで動かしています。利用者は運営者だけで、運営者はこのツールを使う前にこのポリシーに同意します。このページは、このツールの Google の設定（同意画面の設定）にも登録しています。

このツールは「AIKAの10分でわかるAIニュース」のほかに、同じ運営者のもう一つの YouTube チャンネルにも使っています。どちらも運営者自身のチャンネルで、ほかの人のチャンネルには使いません。このポリシーは、どちらのチャンネルにも同じように当てはまります。

2. YouTube API サービスと Google プライバシーポリシー

このツールは YouTube API サービスを使っています。使っているのは YouTube Data API、YouTube Analytics API、YouTube Reporting API の三つです。YouTube と Google が情報をどう扱うかは、Google プライバシーポリシーをご覧ください。YouTube の利用には YouTube 利用規約が適用されます。

3. 求める許可（スコープ）とその理由

Google の同意画面で求める許可は、次の四つです（プログラムによっては、その一部だけを求めます）。対象は、運営者自身の Google アカウントと YouTube チャンネルだけです。

youtube.upload
YouTube の動画を管理するための許可です。動画のアップロードと、サムネイルの設定に使います。
youtube.force-ssl

YouTube の動画、評価、コメント、字幕を見たり、編集したり、完全に削除したりできる広い許可です。実際に使うのは、次の三つだけです。

  • 字幕を付ける
  • 動画を再生リストに入れる
  • 送信中に動画ファイルが書き換えられたときに、公開の予約を取り消して、動画を非公開のままにする

動画、コメント、字幕を削除したり、評価を付けたりはしません。

youtube.readonly
YouTube アカウントの情報を見るための許可です。正しいチャンネルかの確認、アップロード済みの動画の一覧と状態の確認、レポートに載せる動画のタイトルと長さの取得に使います。
yt-analytics.readonly
YouTube アナリティクスのレポートを見るための許可です。再生回数や総再生時間といったチャンネルの数字を読むのに使います（YouTube Analytics API と YouTube Reporting API）。毎日のレポートを YouTube に作ってもらう設定（Reporting API のジョブ）を作るのにも使います。

推定収益などの収益の数字を見る許可（yt-analytics-monetary.readonly）は求めていません。求めるようにするときは、先にこのページを直します。

4. 受け取る情報と保存する情報

Google と YouTube から受け取るのは、次の情報です。どれも運営者自身のアカウントとチャンネルについてのものです。

  • 認証のトークン: このツールが運営者の代わりに YouTube を使うために、Google が発行する鍵です。
  • チャンネルの情報: チャンネル ID、チャンネル名、登録者数、総再生回数、動画の本数、長い動画とカスタムサムネイルが使えるかどうか。
  • 動画の情報: 動画 ID、タイトル、タグ、公開日時、動画の長さ、公開の状態（非公開・公開など）、アップロードと処理の状態。
  • チャンネルの数字: 再生回数、総再生時間、平均視聴時間、視聴維持率、高評価・コメント・共有の数、登録者の増減、流入元、サムネイルの表示回数とクリック率など。日ごと、動画ごと、国や地域ごとなどの内訳を含みます。どれも YouTube が集計した数字です。

視聴者一人ひとりの情報（名前、メールアドレス、コメントの本文など）は受け取りません。運営者の Google アカウントのメールアドレスやプロフィールも受け取りません。

受け取った情報の一部と、ツール自身の作業の記録（どの回をどの動画として上げたか、サムネイルや字幕の設定が済んだか、など）は、運営者のパソコンにファイルとして保存します。ブラウザの Cookie や広告用の識別子は使いません。

5. 情報の使いみち

受け取った情報は、運営者のために次のことをする目的でだけ使います。

  • 運営者の動画を投稿し、公開の予約、サムネイル、字幕、再生リストを設定する
  • 投稿の前後に、正しいチャンネルか、同じ回を二重に上げていないか、予定どおり公開されたかを確かめる
  • 運営者がチャンネルを良くするためのレポートを、パソコンの中に作る

投稿する動画と公開の設定は、運営者が決めます。通常は「非公開」で上げて、公開日時を予約します。運営者が決めた予定に沿って、決まった時刻に自動で投稿することもあります。「AIKAの10分でわかるAIニュース」では、運営者が中身を確かめて承認した回だけを投稿します。このツールが運営者の操作なしに公開の設定を変えるのは、運営者があらかじめ決めた次の場合だけです。送信中に動画ファイルが書き換えられたときは、承認していない中身が公開されないよう、公開の予約を取り消して非公開のままにします。

次のことはしません。

  • データを売ること
  • データを広告に使うこと、広告のために誰かに渡すこと
  • 人の行動を追跡（トラッキング）すること
  • 運営者以外のチャンネルについて、データを集めること
  • AI モデルの学習のためにデータを使うこと、学習のために誰かに渡すこと

AIKA Channel Tools が Google API から受け取った情報の利用と移転は、Google API サービスのユーザーデータに関するポリシーに従います。これには Limited Use（利用の制限）の要件も含みます。

6. ほかのサービスに渡す場合

情報を渡す先は、次の三つのサービスだけです。

YouTube（Google）
運営者の指示で、動画とその情報（タイトル、説明文、タグ、サムネイル、字幕）を YouTube に送ります。あわせて、公開の予約と、動画の設定（子ども向けかどうか、改変・合成したコンテンツを含むかどうか など）も送ります。分析のときは、YouTube に数字を問い合わせます。また、毎日のレポートを YouTube に作ってもらうための設定（Reporting API のジョブ）を作ります。
Anthropic（AI アシスタントの Claude）
運営者は、AI アシスタントの Claude（Anthropic 社のサービス）に、このツールを動かす作業を手伝わせることがあります。また、このツールが作ったレポートや記録を Claude に読ませて、チャンネルを良くするための提案を受けます。そのときは、その中身（運営者自身のチャンネルの数字、動画のタイトルや ID など）が Anthropic に送られ、Anthropic の利用条件に従って処理されます。運営者は Claude を、送った内容が AI モデルの学習に使われない条件（Anthropic の商用の利用条件）でだけ使います。使う目的は、運営者が自分のチャンネルを運営することだけです。認証のトークンは渡しません。
Cloudflare（DNS）
パソコンの名前解決（DNS）がうまくいかないときに限り、Cloudflare の公開 DNS（1.1.1.1）を使います。Google のサーバーのアドレスを調べるために、サーバー名（例: www.googleapis.com）を問い合わせるだけです。YouTube のデータやトークンは送りません。

YouTube から受け取った情報を、このほかの人や会社に渡すことはありません（法令に基づいて開示を求められた場合を除きます）。広告は表示せず、第三者がこのツールを通じてコンテンツや広告を配信することもありません。

7. 保存する場所と期間

情報を保存するのは、運営者自身のパソコンの中だけです。6に書いた場合を除き、ほかの場所には送りません。保存する場所には、このツールのフォルダのほか、AI アシスタント（6）とのやりとりの記録や、運営者が作業のメモに写した分も含みます。下の期間は、そのどれにも当てはめます。

認証のトークン
運営者のアカウントだけが読める場所に保存し、画面やログには出しません。持つのはこのツールを使う間だけで、許可を取り消したら消します。
数字（YouTube Analytics API と YouTube Reporting API のデータ、再生回数や登録者数などの統計）
レポートに必要な間は保存します。その間も、少なくとも30日に1回、許可がまだ有効か、動画がまだ YouTube にあるかを確かめます。
それ以外の情報（動画のタイトル、チャンネル名、公開の状態など）
保存してから30日以内に、消すか、YouTube から取り直して新しくします。

Google との通信は、すべて暗号化（HTTPS）されています。

この方針は、2026年10月4日から当てはめます。それより前から保存していた情報（もう一つのチャンネルの古い記録など）も、2026年11月3日までにこの方針に合わせて、消すか、YouTube から取り直して新しくします。

8. 許可の取り消しとデータの削除

許可はいつでも取り消せます。取り消す方法は二つあります。

このツールのコマンドで取り消す

「AIKAの10分でわかるAIニュース」の許可は、運営者のパソコンで次のコマンドを実行して取り消します。誤って動かないよう、端末で yes と入力したときだけ動きます。

.venv/bin/python tools/yt/auth.py --revoke

Google への許可をその場で取り消し、パソコンにあるトークンを消します。そのあと7日以内に、このツールが保存した YouTube のデータも消します（下の「保存したデータだけを消す」のコマンドを使います）。もう一つのチャンネルの許可は、下の Google のページで取り消します。

Google のページで取り消す

AIKA Channel Tools の許可は、Google のセキュリティ設定のページからも、いつでも取り消せます。

https://security.google.com/settings/security/permissions

取り消されたトークンは更新できなくなるので、このツールは次に YouTube に接続したときにそれに気づきます。この場合は、取り消しから30日以内に、手元のトークンと保存したデータを消します。ほかの理由でトークンが更新できなくなり、認証し直さないときも同じです。「AIKAの10分でわかるAIニュース」では、上の --revoke と下の --delete-data を使います。

保存したデータだけを消す

許可を残したまま、保存したデータだけを消すこともできます。データの削除を求められたときは、7日以内に消します。「AIKAの10分でわかるAIニュース」の分は、次のコマンドを実行すると、このツールがパソコンに保存した YouTube のデータを消します。これも、端末で yes と入力したときだけ動きます。もう一つのチャンネルの分は、運営者が手で消します。

.venv/bin/python tools/yt/auth.py --delete-data

--dry-run を付けると、何も消さずに、消すものだけを表示します。運営者が自分で作ったもの（動画ファイルや説明文の原稿など）と、同じ回を二重に投稿しないための手元の印（投稿済みかどうか、日時など）は消しません。

運営者のパソコンにある、AI アシスタントとのやりとりの記録や作業のメモに写した YouTube の情報（7）も、同じ期限までに運営者が手で消します。

このツールが保存したデータを消しても、YouTube 上のデータ（動画、コメント、アナリティクスなど）は消えず、何も変わりません。YouTube 上のデータを消すときは、YouTube（YouTube Studio など）か、削除の機能がある許可済みのアプリを使ってください。

1. Scope of this policy

This policy describes how AIKA Channel Tools (“the tool”) handles the information it receives through YouTube API Services. “The tool” means all of the operator’s programs that use the same Google authorization settings (OAuth client).

The tool was built by the operator of the YouTube channel “AIKAの10分でわかるAIニュース【毎朝7時更新】” (“the operator”) and runs on the operator’s own computer. The operator is its only user and agrees to this policy before using it. This page is also registered in the tool’s Google settings (its consent screen configuration).

Besides “AIKAの10分でわかるAIニュース”, the tool is also used for one other YouTube channel run by the same operator. Both are the operator’s own channels; the tool is never used for anyone else’s. This policy applies in the same way to both channels.

2. YouTube API Services and the Google Privacy Policy

The tool uses YouTube API Services, namely the YouTube Data API, the YouTube Analytics API and the YouTube Reporting API. For how YouTube and Google handle information, see the Google Privacy Policy. Use of YouTube is governed by the YouTube Terms of Service.

3. Permissions (scopes) requested and why

On Google’s consent screen, the tool asks for the four permissions below (some programs ask for only some of them). They cover only the operator’s own Google accounts and YouTube channels.

youtube.upload
Lets the tool manage YouTube videos. The tool uses it to upload videos and set their thumbnails.
youtube.force-ssl

A broad permission to see, edit and permanently delete YouTube videos, ratings, comments and captions. The tool uses it for these three things only:

  • adding captions;
  • adding videos to playlists;
  • if a video file changes while it is being uploaded, canceling the scheduled publication and keeping the video private.

It never deletes videos, comments or captions, and never rates videos.

youtube.readonly
Lets the tool view the YouTube account. It is used to confirm that the channel is correct, to check the list and status of uploaded videos, and to get video titles and lengths for reports.
yt-analytics.readonly
Lets the tool view YouTube Analytics reports. It is used to read channel statistics such as views and watch time (YouTube Analytics API and YouTube Reporting API), and to set up YouTube to prepare daily reports (Reporting API jobs).

The tool does not ask for permission to view revenue figures such as estimated revenue (yt-analytics-monetary.readonly). If that changes, this page will be updated first.

4. Information received and stored

From Google and YouTube, the tool receives the following information, all of it about the operator’s own accounts and channels:

  • Authorization token: a key issued by Google that lets the tool use YouTube on the operator’s behalf.
  • Channel information: channel ID, channel name, subscriber count, total views, number of videos, and whether long videos and custom thumbnails are enabled.
  • Video information: video ID, title, tags, publish date and time, length, privacy status (private, public, etc.), and upload and processing status.
  • Channel statistics: views, watch time, average view duration, audience retention, numbers of likes, comments and shares, subscribers gained and lost, traffic sources, thumbnail impressions and click-through rate, and similar figures, including breakdowns by day, by video, and by country or region. All of them are aggregated by YouTube.

The tool does not receive information about individual viewers (such as names, email addresses or comment text). It also does not receive the email address or profile of the operator’s Google account.

Some of this information, together with the tool’s own work records (for example, which episode was uploaded as which video, and whether its thumbnail and captions were set), is saved as files on the operator’s computer. The tool does not use browser cookies or advertising identifiers.

5. How information is used

The information is used only to do the following for the operator:

  • upload the operator’s videos and set their scheduled publication, thumbnails, captions and playlists;
  • check, before and after uploading, that the channel is correct, that the same episode is not uploaded twice, and that the video went public as scheduled;
  • create reports on the operator’s computer that help the operator improve the channel.

The operator decides which videos are uploaded and their privacy settings: normally a video is uploaded as private and scheduled to go public at a set date and time. Uploads may also run automatically at a set time, following a schedule the operator set. For “AIKAの10分でわかるAIニュース”, the tool uploads only episodes whose content the operator has checked and approved. The tool changes a privacy setting without the operator’s action in only one case, which the operator decided in advance: if the video file changes while it is being uploaded, the tool cancels the scheduled publication and keeps the video private, so that unapproved content is not published.

The tool never:

  • sells data;
  • uses data for advertising, or gives it to anyone for advertising;
  • tracks people’s behavior;
  • collects data about channels other than the operator’s;
  • uses data, or gives it to anyone, to train AI models.

AIKA Channel Tools’ use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

6. Sharing with other services

Information handled by the tool goes only to the following three services.

YouTube (Google)
At the operator’s direction, the tool sends YouTube the videos and their details (titles, descriptions, tags, thumbnails and captions), the scheduled publication times, and video settings (such as whether a video is made for kids and whether it contains altered or synthetic content). For analysis, it asks YouTube for statistics. It also sets up YouTube to prepare daily reports (Reporting API jobs).
Anthropic (the AI assistant Claude)
The operator has Claude, an AI assistant provided by Anthropic, help run the tool, and has it read the reports and records created by the tool to suggest how to improve the channels. When this happens, their content (for example, statistics, video titles and video IDs of the operator’s own channels) is sent to Anthropic and processed under Anthropic’s terms. The operator uses Claude only under terms where the content sent is not used to train AI models (Anthropic’s commercial terms), and only to run the operator’s own channels. The authorization token is never shared.
Cloudflare (DNS)
Only when the computer’s normal address lookup (DNS) fails, the tool uses Cloudflare’s public DNS service (1.1.1.1). It only asks for the address of Google’s servers by server name (for example, www.googleapis.com), and never sends YouTube data or tokens.

Except where disclosure is required by law, information received from YouTube is not given to any other person or company. The tool shows no ads, and no third party serves content or ads through it.

7. Where data is stored and for how long

Data is stored only on the operator’s own computer. Except as described in section 6, it is not sent anywhere else. Storage includes the tool’s own folders, the records of conversations with the AI assistant (section 6), and any copies in the operator’s working notes. The periods below apply to all of them.

Authorization token
Stored where only the operator’s account can read it, and never shown on screen or in logs. It is kept only while the tool is in use and deleted when permission is revoked.
Statistics (YouTube Analytics API data, YouTube Reporting API data, and statistics such as view and subscriber counts)
Kept as long as the reports need them. During that time, the operator confirms at least every 30 days that the permission is still valid and that the videos still exist on YouTube.
All other information (video titles, channel name, privacy status, etc.)
Deleted, or refreshed from YouTube, within 30 days of being stored.

All communication with Google is encrypted (HTTPS).

This policy applies from October 4, 2026. Information stored before that date (such as older records for the other channel) will also be brought in line with this policy by November 3, 2026: deleted, or refreshed from YouTube.

8. Revoking permission and deleting data

Permission can be revoked at any time, in either of two ways.

Revoke with the tool’s command

For “AIKAの10分でわかるAIニュース”, run the following command on the operator’s computer. To prevent accidents, it runs only after “yes” is typed at the terminal.

.venv/bin/python tools/yt/auth.py --revoke

It revokes the permission at Google right away and deletes the token from the computer. Within 7 days after that, the YouTube data stored by the tool is also deleted (with the command in “Delete only the stored data” below). Permission for the operator’s other channel is revoked on Google’s page, described next.

Revoke on Google’s page

You can also revoke the access of AIKA Channel Tools at any time on Google’s security settings page:

https://security.google.com/settings/security/permissions

A revoked token can no longer be refreshed, so the tool notices the next time it connects to YouTube. In this case, the local token and the stored data are deleted within 30 days of the revocation. The same applies when a token can no longer be refreshed for any other reason and is not authorized again. For “AIKAの10分でわかるAIニュース”, this is done with --revoke above and --delete-data below.

Delete only the stored data

The stored data can also be deleted while keeping the permission. When deletion is requested, the data is deleted within 7 days. For “AIKAの10分でわかるAIニュース”, the following command deletes the YouTube data that the tool has stored on the computer; it also runs only after “yes” is typed at the terminal. For the operator’s other channel, the operator deletes the data by hand.

.venv/bin/python tools/yt/auth.py --delete-data

Adding --dry-run shows what would be deleted without deleting anything. Things the operator made (such as video files and description drafts) and the local markers that prevent the same episode from being uploaded twice (such as whether it was uploaded, and when) are kept.

YouTube information copied into the records of conversations with the AI assistant, or into the operator’s working notes, on the operator’s computer (section 7) is also deleted by the operator, by hand, within the same deadlines.
