AIKA Channel Tools

日本語

YouTube チャンネル「AIKAの10分でわかるAIニュース【毎朝7時更新】」の運営者が、自分で使うために作った個人用のツールです。自分のチャンネルに動画を投稿し、チャンネルの数字を分析します。

運営者だけが使う、公開していないツールです

AIKA Channel Tools は、運営者のパソコンの上で動くプログラムです。使う先は運営者自身の YouTube チャンネルだけで、このチャンネルと、同じ運営者のもう一つのチャンネルに使っています。ほかの人には提供しておらず、このサイトにも申し込みやログインの窓口はありません。

できること

動画の投稿
運営者が作った動画を、運営者が決めた予定どおりに YouTube にアップロードします。決まった時刻に自動で動かすこともあります。動画は通常「非公開」で上げ、運営者が決めた日時に公開されるよう予約します。タイトル、説明文、タグ、サムネイル、字幕も設定し、再生リストに入れます。
投稿の確認
投稿の前に、同じ回をすでに上げていないかを確かめます。「AIKAの10分でわかるAIニュース」では、運営者が中身を確かめて承認した回だけを上げます。投稿の前には正しいチャンネルかを、公開の時刻を過ぎたら予定どおり公開されたかも確かめます。
チャンネルの分析
再生回数、総再生時間、視聴維持率、流入元、登録者の増減、サムネイルの表示回数とクリック率といった数字を YouTube から読み、運営者向けのレポートをパソコンの中に作ります。

YouTube API サービスを使っています

このツールは YouTube API サービスを使っています。使っているのは YouTube Data API、YouTube Analytics API、YouTube Reporting API の三つです。動くのは、運営者が Google の画面で許可した範囲の中だけです。このツールを使う人は、YouTube 利用規約に拘束されることに同意したことになります。Google による情報の扱いは、Google プライバシーポリシーに書かれています。

AIKA Channel Tools は、YouTube や Google が作ったものでも、認めたものでもありません。

A personal tool that the operator of the YouTube channel “AIKAの10分でわかるAIニュース【毎朝7時更新】” built for their own use. It uploads videos to the operator’s own channels and analyzes their statistics.

A private tool used only by its operator

AIKA Channel Tools is a program that runs on the operator’s own computer. It is used only for YouTube channels that the operator owns: this channel and one other channel run by the same operator. It is not offered to anyone else, and this site has no sign-up or login.

What it does

Uploading videos
Uploads videos made by the operator, on the schedule the operator set. Uploads may also run automatically at a set time. A video is normally uploaded as private and scheduled to go public at the date and time the operator chose. The tool also sets the title, description, tags, thumbnail and captions, and adds the video to a playlist.
Checking uploads
Before uploading, it checks that the same episode has not already been uploaded. For “AIKAの10分でわかるAIニュース”, it uploads only episodes whose content the operator has checked and approved. It also confirms that the channel is correct before uploading, and that the video went public as planned after the scheduled time.
Analyzing the channel
Reads statistics from YouTube, such as views, watch time, audience retention, traffic sources, subscribers gained and lost, and thumbnail impressions and click-through rate, and creates reports for the operator on the operator’s computer.

It uses YouTube API Services

The tool uses YouTube API Services (the YouTube Data API, the YouTube Analytics API and the YouTube Reporting API) and works only within the permissions the operator grants on Google’s consent screen. By using the tool, users agree to be bound by the YouTube Terms of Service. How Google handles information is described in the Google Privacy Policy.

AIKA Channel Tools is not made or endorsed by YouTube or Google.
